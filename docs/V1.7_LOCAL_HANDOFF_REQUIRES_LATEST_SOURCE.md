## 修复 A：所有内置激励目标可编辑（双端）

当前独立的「激励目标」管理页只有自定义目标可改；内置的 22 个目标也要能点击编辑名称和价格。编辑交互与自定义一致，校验名称非空、价格正数且最多两位小数；确认后实时反映到列表和实际激励算法。内置目标用稳定 ID 匹配用户覆盖值，并以 **Profile/SQLite 存储覆盖**，绝不改包内 JSON；提供单条「恢复默认」按钮。保留已有自定义目标和历史用户数据。

## 修复 B：移除设置页重复置顶（双端）

标题栏已有图钉控制窗口置顶，因此从设置页删除「窗口置顶」复选框。保留标题栏功能、当前置顶持久化与关闭/托盘/重新打开逻辑。不得清掉旧用户的 pinned 状态。

## 修复 C：设置修改保存无效（最高优先级，双端）

用户亲测：设置页修改上班时间、下班时间、工资、满勤奖金后回到默认值/金额不变；午休时间正常，新手引导正常。必须追踪 `Settings.tsx` 草稿状态、`ScheduleFields.tsx` 时间控件回调、`TimePicker.tsx` 滚轮确认、`main.tsx` 的 store/save、Rust `save_profile`/SQLite 持久化及 `profileSnapshot` 重算链路。

特别排查工资输入使用 `defaultValue` 与 React 受控草稿混用，以及异步 setState/旧 closure 导致字段被覆盖。金额文本输入需保留小数输入的草稿串，最终确认再解析为整数分，防止光标跳转/丢失句点。保存成功须等待持久化完成并通过读回核实后再离开设置页；保存失败必须显示错误。每次修改时薪、基础工资、满勤奖的计算都须正确更新，重启保持。
